# Навык interview

Гайд интервью (без наводящих вопросов, восстановление последнего случая), анализ конспектов (кодирование → темы → частоты с n). Синтетические беседы — через субагента synthetic-respondent, только для гипотез

После выполнения: обнови state.json и выполни `python tools/sfp.py log <slug> <step> "<итог>" --tokens N --minutes M`.
