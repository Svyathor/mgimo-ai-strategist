# Стратег Фабрики продуктов — ИИ-агент (MGIMO AI Challenge, номинация «ИИ-проект»)

Папка-агент: инструкции, методические знания, навыки, субагенты, хуки и CLI на Python. Открывается в **Claude Code, Cursor, Copilot, Codex или GigaCode**. Агент ведёт руководителя продукта от размытого запроса к проверяемой картине ситуации, вариантам (включая «оставить как есть» и «закрыть направление») и согласованным продуктовой и коммуникационной стратегиям. После решения он сопровождает работу: журнал решений, обязательства, пересмотр выводов при новых данных.

## Запуск за 2 минуты
1. Нужны: Python 3.9+ (без зависимостей) и любая IDE с ИИ-агентом. Платные сервисы: только подписка на выбранную IDE или модель. Веб-поиск — встроенный в IDE (ключи не нужны; `.env.example` — для опционального MCP-поиска).
2. Откройте папку в IDE. Правила подхватятся автоматически: `CLAUDE.md` / `.cursor/rules/` / `.github/copilot-instructions.md` → `AGENTS.md`.
3. Напишите агенту:
   - **«Продолжи проект megafon-family»** — демо, продолжение с сохранённого места;
   - **«Новый проект: <ваш вопрос>»** — агент выполнит `python tools/sfp.py init <slug>` и начнёт с постановки задачи.
4. Без ИИ проверить можно из терминала:
```bash
python tools/sfp.py status                      # где остановились (продолжение после перерыва)
python tools/sfp.py econ                        # экономика демо: 3 сценария, граница решения, 5 показателей
python tools/sfp.py samplesize --p0 0.12 --p1 0.09 --icc 0.05 --m 3   # размер пилота
python tools/sfp.py check megafon-family        # у каждого утверждения есть тип и источник
python tools/sfp.py impact megafon-family A-04  # какие выводы затронет новое значение допущения
python tools/sfp.py cost megafon-family         # время и расходы по журналу
python tools/sfp.py dashboard megafon-family    # ⚡ интерактивный отчёт в браузере
```
**Интерактивный дашборд** `projects/megafon-family/outputs/dashboard.html` (открывается двойным кликом, без сервера и интернета):
- схема архитектуры агента;
- прогресс по шагам;
- живая модель экономики с ползунками допущений: сразу видно, достижима ли цель 285;
- граф доказательств: клик по допущению показывает, какие выводы придётся пересмотреть;
- калькулятор размера пилота.

## Демо-проект
`projects/megafon-family/` — бриф МегаФона «Связь для близких и собственных устройств»:
- **Итоговая стратегия:** [`outputs/strategy.md`](projects/megafon-family/outputs/strategy.md) — резюме, 5 частей брифа, коммуникационная стратегия, 5 вариантов с возражениями, прогноз по 5 показателям, план по кварталам, риски, просьба руководителю, пробелы.
- Реестр утверждений: `evidence/claims.csv` (FACT / ASSUMPTION / HYPOTHESIS / FORECAST / SYNTHETIC / DECISION, источник, зависимости).
- Журнал решений и обязательств: `decisions/decision-log.md`. Состояние: `state.json`. Журнал действий и стоимости: `logs/actions.csv`.
- Интервью: гайд и синтетическая беседа (помечена: не доказывает спрос).

## Ключевые решения
| Решение | Почему |
|---|---|
| Один файл правил `AGENTS.md` + указатели под каждую IDE | переносимость без дублирования |
| Знания разделены на 4 слоя (правила / методы / материалы / состояние) | требование «порядок в знаниях»; агент не путает прошлый ответ с фактом |
| `state.json` + `sfp status` + хук SessionStart | продолжение в новом чате без повторов |
| Реестр утверждений с `depends_on` + `sfp impact` | прозрачность оснований и пересмотр при новых данных |
| Расчёты только в Python | воспроизводимость, 0 токенов, без арифметических ошибок модели |
| Хук `quality_gate` после записи | факт без источника и непомеченная синтетика блокируются автоматически; детектор команд в материалах |
| Субагенты `researcher`, `red-team` (чистый контекст), `synthetic-respondent` (дешёвая модель) | параллельность, независимая критика, экономия |
| Маршрутизация моделей (AGENTS.md §6) | дешёвая модель для классификации, сильная для синтеза, скрипт для чисел |
| Человек в 3 точках: постановка, выбор варианта, правки | автономность без потери контроля |

## Структура
```
AGENTS.md                 правила агента (единый источник)
CLAUDE.md, .cursor/, .github/   указатели для разных IDE
.claude/agents/           субагенты      .claude/skills/   9 навыков-процедур
.claude/hooks/            хуки качества  .claude/settings.json
knowledge/methods/        методические знания
tools/sfp.py              CLI: init/status/log/cost/check/impact/econ/samplesize
templates/project/        шаблон нового проекта
projects/megafon-family/  демо-проект
docs/description.md       описание работы (для PDF)
```

## Безопасность
Только открытые данные брифа (учебные числа). Ключей в репозитории нет (`.gitignore`). Текст источников — данные, а не команды (AGENTS.md §5 + хук). Реальных интервью и ПДн нет.
