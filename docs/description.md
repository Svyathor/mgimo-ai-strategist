# Описание работы: «Стратег Фабрики продуктов»

## 1. Архитектура агента
- **Процесс:** 8 шагов (0-intake → 7-after-decision), см. AGENTS.md §2. На каждом шаге есть навык (`.claude/skills/*`), понятный результат и, где нужно, контрольная точка человека (постановка, выбор варианта, правки).
- **Контекст и знания (4 слоя):** постоянные правила (`AGENTS.md`, агенты, навыки) · методы (`knowledge/methods`) · материалы проекта (`projects/<slug>/inputs`) · состояние (`state.json`, `claims.csv`, `logs`, `decisions`).
- **Инструменты:** `tools/sfp.py` (CLI), встроенные Read/Write/WebSearch IDE, субагенты, хуки.
- **Продолжение после перерыва:** хук SessionStart → `sfp status`. Агент читает `steps_done` и `next_action` и не повторяет выполненное.
- **Пересмотр:** граф зависимостей `depends_on` в `claims.csv` → `sfp impact` показывает затронутые выводы и разделы.

## 2. Модели, сервисы, инструменты
| Что | Для чего |
|---|---|
| Claude Opus 5.5 (Claude Code) | основной агент: исследование, синтез, стратегия; субагент red-team |
| Claude Sonnet / Haiku | назначены субагентам researcher и synthetic-respondent (в демо не запускались) |
| Python 3 (stdlib) | расчёты экономики, размера пилота, проверки и графа зависимостей |
| Claude Code hooks | quality gate после записи, статус при старте |
| Chrome (Claude in Chrome) | чтение страницы задания и брифа |
Альтернатива: в Cursor, GigaCode или Copilot тот же репозиторий работает через `.cursor/rules` и `.github/copilot-instructions.md`.

## 4. Реализованные возможности дополнительного уровня
- Интервью и модельные респонденты: гайд, синтетическая беседа с маркировкой SYNTHETIC и проверкой хуком.
- Анализ данных: воспроизводимые расчёты (сценарии low/base/high, граница решения, окупаемость, размер выборки с кластеризацией).
- Поддержка решений: `decision-log.md` (ответственные, показатели, условия пересмотра, что решать сейчас, устаревающие основания).
- Пересмотр при новых данных: `sfp impact`, статус retracted, проверка, что отозванная запись не используется.
- Маршрутизация моделей и инструментов, навыки, хуки, субагенты, CLI.
- Устойчивость: журнал действий, проверка перед повтором, открытые вопросы в состоянии.
- Переносимость: единый AGENTS.md и указатели для 3 IDE.
- Не реализовано (ограничения): MCP-интеграции с внешними данными (только встроенный поиск IDE), анализ изображений и видео интерфейсов, измеренное сравнение с аналитиком вручную.

## 5. Время и расходы на демо-проект
- Реальное время сеанса Claude Code (Opus 5.5): с 23:19 (бриф скачан) до ≈ 23:35 (финальный архив), то есть ≈ 20 минут вместе с чтением задания и брифа.
- Токены — **оценка** ≈ 200 тыс. [TODO: вставить точную цифру из `/cost` сеанса]. Других платных сервисов нет.

## 6. Заявленные возможности и ограничения
- Числа брифа учебные. Частоты причин и отток — допущения с диапазонами (пробелы G-01…G-05).
- Веб-исследование в демо не проводилось: все факты взяты из брифа и снабжены страницами.
- Реальных интервью нет. Синтетика используется только для гипотез.
