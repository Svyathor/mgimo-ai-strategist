# Экономика
- Прибыль = база «без изменений» + доп. оплаченные месяцы × маржа + экономия, которая реально исчезает − новые прямые расходы.
- Каждое слагаемое: объём × цена × период. Работа последнего месяца года даёт ≤1 доп. месяц.
- Граница решения: значение ключевого допущения, при котором цель достижима. Неизвестная цена → формула + значение, которое нужно узнать.
- Окупаемость: накопленная доп. прибыль vs вложения по кварталам; предельные вложения за заданный срок.
