# Доказательность
- FACT — есть проверяемый источник (файл+стр., URL+дата). ASSUMPTION — число для расчёта до проверки, всегда с диапазоном. HYPOTHESIS — утверждение + наблюдение, которое его опровергнет. FORECAST — результат расчёта из допущений. SYNTHETIC — ответ ИИ-респондента, не доказательство.
- Сигнал ≠ причина: «не отвечает» не означает «кончился интернет».
- Отзыв записей: не удалять, а ставить status=retracted и проверять `sfp check`, что запись больше нигде не используется.
