# Проверка (пилот)
- Метрика заранее: числитель, знаменатель, единица (человек/группа/номер/операция), окно наблюдения.
- Рандомизация по кластеру, если участники влияют друг на друга (общий пакет → по семье). DEFF = 1 + (m−1)·ICC.
- Intention-to-treat: в расчёте все включённые, а не только открывшие сообщение.
- Порог и разброс согласовать до запуска; ДИ включает и 0, и полезный эффект → данных недостаточно.
- Темп набора: n_групп / недели набора; плюс окно наблюдения за последними.
- Стоп-условия: утечка данных после отзыва, двойные списания.
