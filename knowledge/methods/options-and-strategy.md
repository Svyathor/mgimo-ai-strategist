# Варианты и стратегия
- Варианты различаются механизмом (уведомление / тариф / новый интерфейс / ничего / закрыть), а не дозировкой.
- Для каждого: польза, кому доступно, затраты, срок первых результатов, последствие ошибки, сильное возражение, что заставит выбрать его.
- Дешёвый вариант с почти той же пользой выигрывает. Назови наблюдение, которое оправдает переход к дорогому.
- Продуктовая стратегия: JTBD (ситуация → мотив → результат), альтернативы клиента, осознанные отказы, unit-экономика.
- Коммуникационная: ситуация → барьер → ключевое сообщение → подтверждение → каналы → чего не обещаем.
